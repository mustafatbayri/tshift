## What the product is
A workforce shift-planning engine (`cozucu/model.py` builds a CP-SAT model; `cozucu/coz.py` runs the search; `dogrulayici/` is an independent validator). The objective is a weighted sum of soft penalties stored in `kuruldu.cezalar` as (weight, IntVar) pairs. Penalty variable name prefixes: `he_` target shortfall (persons per hour-cell), `ha_` target overshoot, `me_` break-time coverage shortfall, `ag_` fairness, `sd_` contract-hours deviation (only when that rule is soft), `fm_` OVERTIME IN MINUTES per person. Product weights per profile DENGELI/KAPSAMA/CALISAN: target shortfall 9/20/5, overshoot 3/1/4, break coverage 7/9/6, fairness 5/2/8, overtime 50 per MINUTE in all profiles (so 1 hour overtime = 3000 points). A request may override any weight via `girdi["agirliklar"] = {CODE: number}` (see `Model._agirlik`).
For large models the flow is: stage 1 find a feasible plan with breaks fixed (`_ipucu_ver`), then improve with the objective (`_ilk_asamada_iyilestir`), then a "break step" with assignments fixed. Small models (fewer than `iki_asama_esigi` = 50,000 variables) skip stage 1 and solve the full model in one joint search (tests force the staged flow with `iki_asama_esigi: 0`).

## What changed (decision "K-61")
1. `VARSAYILAN["fazla_mesai_once_sifir"]` flipped False -> True. With it, stage 1 first searches for a feasible plan with every `fm_*` variable's domain fixed to [0,0] ("overtime-free first"). If found, overtime stays 0 in all later stages. If not found (proved infeasible, or time ran out) the domains are restored and the old path runs, with a note.
2. NEW guard `_fazla_mesai_kisayolu_gecerli(kuruldu)`: the product owner's principle is "the weights are the judge: if by the weights a plan WITH overtime is clearly better than the overtime-free plan, the engine must choose it". The overtime-free-first search excludes overtime plans whenever an overtime-free plan exists, so it is only a SHORTCUT. The guard applies the shortcut only if (overtime weight per minute) >= (largest weight among all other penalty terms); otherwise the shortcut is skipped, `kuruldu.fazla_mesai_once_sifir = {"uygulandi": False, "sebep": "agirlik", ...}` is reported and a note is appended.
3. Tests added/changed in `testler/test_fazla_mesai_once_sifir.py` (16 -> 26 tests), one assertion in `testler/test_demir_secenekleri.py`.
4. Mutation harness `mutasyon_kostur.py`: group `fm_sifir` grew 29 -> 44 entries (tuples `(group, file, name, old_text, new_text, test_file)`; `old_text` must occur exactly once in the file).
5. Measurement tool `kalite-olc.py`: product-state configs now inherit the option from the engine default; 16 historical "record" configs pin it off (`KAPALI`); new `etkin_ayar`, `once_fazla_mesaisiz` field; `fm_once_yazisi` handles the skipped case.
